## 用户操作复测

使用全新的 Chrome 157 和 Edge 158 配置加载 v0.2.0 ZIP。按课程页面上的按钮走通双视频、教材和下一小节。视频暂停后从原进度续播，教材暂停时停止滚动，手动选小节后需再次点击「开始」。播放时静音不会打断视频，刷新两个课程标签页后，只有被静音的标签页显示「取消静音」。

测验和未获完成确认的任务会停下来等待用户处理。下一小节锁定时也会停下，面板提示去目录选择下一节，提示中没有写明锁定原因。

v0.2.1 在 Chrome 和 Edge 的样例中复测了两种情况。下一小节锁定时，面板显示「下一小节尚未开放」。下一小节已开放且目录保留隐藏的锁图标时，课序仍能接续播放。

v0.2.2 在 Chrome 和 Edge 的编号页签样例中，从「1 慕课视频」仅显示完成标记的状态开始，验证自动打开「2 教材+PPT」、滚动内层阅读器、等待教材确认，再进入下一小节播放。Chrome 另复测了从两条未完成视频开始的流程，以及教材滚到底后缺少完成标记时停留在页签 2。

v0.2.3 在 Chrome 和 Edge 中验证了同页三份资料的样例。课序跳过已完成的第一份，滚动没有任务标记的中间资料，再发现并处理下方延迟加载的任务点。Chrome 另验证前一个任务点未确认时仍会滚动后续资料，并在本小节等待确认。

v0.3.0 分别在 Chrome 的整页跳转样例和 Edge 的页内跳转样例中，从一次「开始」连续处理四个目标小节，覆盖视频加多份资料、纯教材、纯视频及教材在前的视频小节。复测包含略过目录里可识别的图谱、讨论和测验，再略过打开后识别出的独立答题页，最后停在目录末尾。两款浏览器也验证了后续小节锁定时的提示。

v0.3.1 用带音轨的视频样例在 Chrome 和 Edge 复测。新小节进入时没有用户操作，带声播放受限后以静音开始，连续接续两条视频和后一个小节。点击「开启视频声音」后当前视频继续播放。手动开始且浏览器允许带声播放的样例也通过。 [Chrome 自动播放规则](https://developer.chrome.com/blog/autoplay)

### v0.3.2 三轮实测

三轮都从扩展 ZIP 装载，在独立的 Chrome 157 和 Edge 158 配置中跑本地课程样例。

| 轮次 | 场景 | 实测结果 |
| --- | --- | --- |
| 1 | 混合目录和带音轨的连续续播 | v0.3.1 和 v0.3.2 均通过。Chrome 连续完成四个目标小节并处理锁定提示。Edge 验证静音续播、开启声音和自动跨节。 |
| 2 | 暂停、手动切节和浏览器侧静音 | Chrome 上旧版面板未同步标签页静音状态，点按钮后标签页仍静音。新版同步浏览器状态并正确切换，手动切节及教材暂停、继续通过。 |
| 3 | 阅读器触底后追加页面和确认超时 | Edge 上旧版在读到第一次底部后等待确认，追加内容留下 776 像素未滚动。新版发现追加内容、滚完并等确认后正常跨节。始终未确认的样例停在当前小节。 |

另在 Chrome 验证了用 v0.2.0 覆盖 v0.1.1 解压目录、在扩展管理页点「重新加载」并刷新课程页的更新过程。

### v0.3.3 四份资料完成状态复测

本地样例中四份资料都滚到底，目录显示完成，页内仍有三份标记未更新。Chrome 157 上的 v0.3.2 停在教材页。Chrome 157 和 Edge 158 加载 v0.3.3 ZIP 后均进入下一小节，视频开始播放。同一目录行同时显示绿勾和剩余任务数时，两款浏览器均停在当前小节，面板显示四份资料均已滚到底或显示完成，并提示待确认数。Edge 也复测了触底后追加页面以及始终未获确认的情况。

适配参考了公开可见的学习通播放器结构和 [学习通网页内容类型识别记录](https://github.com/sorbte/xuexitong/blob/master/页面特点记录.md)。从网页版入口进入已选课程时，可用下列步骤记录兼容性。

1. 打开本节视频，在右下角点「开始」并检查播放和暂停。
2. 等视频自然播完，检查是否依次切换到「教材+PPT」、滚动内层阅读器并在网页确认后进入下一小节。
3. 如停在原页，记录课序提示、浏览器版本、页面路径和任务类型。截图前遮住姓名和账号信息。
